# Superstore Sales & Profitability Analysis

An end-to-end data analytics project exploring sales performance and business health using **Excel, SQLite, and Tableau**.

## 📊 Executive Summary
This project analyzes a multi-region retail transaction dataset to evaluate product profitability and regional sales efficiency. Through multi-stage data processing and SQL investigation, I successfully uncovered operational bottlenecks where high sales numbers actively masked structural losses.

## 🛠️ Tech Stack & Skills
* **Excel:** Data cleaning, conditional formatting, margin engineering.
* **SQL (SQLite):** Aggregations (`SUM`, `COUNT`), date manipulation (`STRFTIME`), conditional filtering.
* **Tableau:** Visual hierarchy, interactive filtering, dashboard assembly.

## 🔍 Key Insights Discovered
* **The Dallas Profit Leak:** Identified a massive profit margin collapse in March (down to 1.64% from January's 20.01%). 
* **The Root Cause:** Isolated a single high-volume transaction in Dallas where \$3,200 in Furniture sales generated a deep loss of -\$450, completely wiping out regional wins.
